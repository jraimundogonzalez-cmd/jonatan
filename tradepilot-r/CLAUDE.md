# CLAUDE.md

Las reglas operativas de TradePilot R viven en **[`AGENTS.md`](./AGENTS.md)**,
en esta misma carpeta. Léelo antes de tocar nada.

Se mantienen ahí y no aquí para que las lea **cualquier** agente de IA, no solo
Claude Code. Este fichero existe únicamente para que Claude Code las cargue
automáticamente al trabajar dentro de `tradepilot-r/`.

El **contexto** del proyecto —qué es, cómo está construido y qué está hecho—
está en [`docs/context/`](./docs/context/), empezando por
[`00_PROJECT_CONTEXT.md`](./docs/context/00_PROJECT_CONTEXT.md).

> Las preferencias de formato de respuesta del usuario están en el `CLAUDE.md`
> de la raíz del repositorio. Este fichero no las sustituye.
