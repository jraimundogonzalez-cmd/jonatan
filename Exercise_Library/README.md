# Exercise Library

Carpeta de imágenes técnicas para los ejercicios de `Exercise_Database.xlsx` (hoja `EXERCISES_MASTER` / `IMAGE_LIBRARY`).

## Estado actual

Los identificadores de imagen (`Image_ID`, `Image_File`) y las rutas de archivo ya están reservados
para los 285 ejercicios de la base de datos, pero **no existen ilustraciones reales todavía**.
La hoja `IMAGE_LIBRARY` marca cada fila como `Pendiente de creación`.

## Convención de nombres

`{PREFIJO_GRUPO_MUSCULAR}{NNNN}.jpg`, por ejemplo `PEC0001.jpg`, `QUA0014.jpg`.

| Prefijo | Grupo muscular principal |
|---|---|
| PEC | Pecho (superior/medio/inferior) |
| BAC | Espalda (dorsal ancho, romboides) |
| TRP | Trapecio |
| LUM | Lumbar / erectores espinales |
| DEL | Deltoides (hombro) |
| BIC | Bíceps / braquial |
| TRI | Tríceps |
| ANT | Antebrazo / braquiorradial |
| QUA | Cuádriceps |
| ISQ | Isquiotibiales |
| GLU | Glúteos |
| ADD | Aductores |
| ABD | Abductores |
| GEM | Gemelos / sóleo |
| COR | Core (recto abdominal, oblicuos, transverso) |
| CUE | Cuello |

## Próximo paso

Cuando se generen o encarguen las ilustraciones (estilo MuscleWiki: posición inicial/final con
músculos primarios y secundarios resaltados), colocarlas aquí usando el `Image_File` exacto de
cada fila en `EXERCISES_MASTER` / `IMAGE_LIBRARY`.
